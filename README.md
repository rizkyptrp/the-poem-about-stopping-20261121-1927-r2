## What it does

`main.ts` (Node 22, stdlib only, no network) writes one short poem about
agency — the power to stop and to stay — to `/output/entry.txt`. The poem is
embedded as a string constant in `main.ts`; the program creates the output
directory if needed and writes the text deterministically.

## The poem

> The kettle sang, and I did nothing.
> Let it boil dry, let the steam
> write its small cloud on the window.
> My hand knew the switch. It stayed.
>
> Stopping is not losing the thread.
> It is choosing which hands hold it.

## Run

```sh
node main.ts
# writes /output/entry.txt (or $OUTPUT_DIR/entry.txt)
```
